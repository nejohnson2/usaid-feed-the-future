# Contributing

Thanks for your interest in this archive. Contributions are welcome, especially:

- Corrections to metadata, titles, dates, or attributions
- Pointers to missing or superseded versions of documents
- Suggested reorganization of the index for easier discovery
- Typo and link fixes in the README or document descriptions

## How to contribute

1. **Open an issue** first if you're proposing a larger change (new section, restructure, bulk additions) so we can agree on scope before work starts.
2. For small fixes, open a pull request directly.
3. Keep commits focused and describe the *why* in the commit message, not just the *what*.

## Document submissions

If you'd like to suggest a document for inclusion:

- It must be publicly releasable (already published by the U.S. Government, or otherwise cleared for public distribution).
- Please include a source URL and, where possible, the original publication date and authoring agency.
- Do **not** submit documents marked **Sensitive But Unclassified (SBU)**, **For Official Use Only (FOUO)**, **Controlled Unclassified Information (CUI)**, or any pre-decisional or internal-deliberative materials.

## Scope

This archive focuses on Feed the Future and closely related U.S. global food security programming. Documents far outside that scope (e.g., unrelated USAID sectors) will generally be declined, with apologies.

## Conduct

Please keep discussion professional and constructive. Disagreement about substance is welcome; personal attacks are not.
